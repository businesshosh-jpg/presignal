# PreSignal v2.1 R6 native Attention call boundary

This boundary authorizes exactly one Gemini / `gemini-2.5-flash-lite` Attention call only after one canonical, upcoming, standalone Episode is selected inside its open cutoff. It makes no forecast, Request, Pack, acquisition, Google scientific write, Outcome, or evaluation call.

The stable v2 prompt returns `session_attention_map` labels. The frozen selection map treats `PRIMARY_DRIVER` as the sole `FORECAST` state, which this narrow native adapter represents as `SELECTED_FOR_INFORMATION_REQUESTS`; all other valid v2 labels are preserved as a valid native non-selection. Historical `WATCH` is never converted.

Pack A verification is deliberately read-only: its governing stable-v2 object is the selected provider's ordered canonical Information Request set with `shared_market_state_pack = None`. It is not Pack E with information removed.
